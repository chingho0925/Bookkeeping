這是「和風旅行記帳 - 自訂幣別與連線查詢版」完整程式碼。

【本次新增重點】
1. 下拉選單「➕ 其他 (自訂/線上查詢)...」選項：
   - 當您點擊選單中的「其他」選項時，會彈出專屬視窗。
2. 連線查詢匯率 API：
   - 在彈窗中輸入英文字母幣別代碼（例如：GBP 英鎊、THB 泰銖、AUD 澳幣、SGD 新加坡幣、HKD 港幣等）。
   - 點擊「🔍 查詢匯率」按鈕，系統會連線免費公開 API 取得該幣別兌換台幣 (TWD) 的最新匯率。
   - 若遇到離線或特殊幣別，亦開放手動修改匯率數值。
3. 自動帶入與儲存：
   - 點擊「確認帶入」後，新幣別會自動加進幣別下拉選單中，並寫入 Local Storage 儲存，未來隨時可直接選用。

【安裝與使用】
解壓縮後直接用瀏覽器開啟 index.html 即可使用；或透過 Chrome 選單「加到主畫面」安裝至手機使用。
